Using LinkedIn to find the rest

  1. Jobs search with a 24-hour filter. Search intern 2028 batch or summer intern 2027, set location to India, Experience level = Internship, Date posted = Past 24 hours. Save the search and turn on the alert.
  2. Posts search, not just Jobs. Startups and many recruiters announce roles only as posts. Search Posts for "hiring interns" 2028 batch, sorted by Latest. Pages like "SDE Jobs and Internships" aggregate these daily with batch and stipend.
  3. Follow the university-recruiting pages. Google Students, Microsoft Students & Graduates, Amazon University, Goldman Sachs Campus, Qualcomm Careers. They post the exact day a window opens.
  4. Referrals beat cold applies. Find alumni of the student's college at the target company (People search → company → school filter). Send a 3-line note with the Job ID and resume link; ask for a referral, not a job.
  5. Make the profile recruiter-searchable. Headline with branch + batch + 2–3 skills (e.g. "CSE '28 · Python · ML · Open to Summer 2027 internships"), Open to Work set to Internship, projects with GitHub links in Featured.
